# Guide: build

Say "Mode: build" and the path chosen. Shared or production work: draft and gate a spec (`draft-spec` or `component`, then `gate-spec`), plan it (`plan`), then `implement`. Contained work: `implement` with a brief stating the outcome, the checks that prove it and the invariants. Say what done means and how it is checked before building.
