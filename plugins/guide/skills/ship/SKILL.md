# Guide — Ship

Say "Mode: ship." Use only the steps the user asked for, in this order: `courier:commit` for the commit message, `courier:changeset` when the repository uses changesets and the change is user-visible, `courier:pr` for the pull request, `courier:release` for release notes. Confirm before anything is pushed, posted or published.
