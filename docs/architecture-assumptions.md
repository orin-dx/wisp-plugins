# Architecture assumptions register

Every part of a harness encodes an assumption about what the model cannot do on its own, and those assumptions go stale as models and hosts change. This register records each load-bearing assumption in `ARCHITECTURE.md` and the decision records, the evidence for and against it, and the check that would retire it. Review it when a new model generation ships, when Claude Code or Codex changes how agents, hooks or plugins work, and before a release. First version: 2026-10-20, from `docs/evaluations/frontend-design/ARCHITECTURE-REVIEW.md` after primary-source verification.

Status: **Holds**, **Changing** (a work package is in progress), **Open** (evidence is mixed; a measurement is planned), **Retire** (evidence says drop it).

## How to update

Add a row when a decision record or architectural section introduces a new assumption. Change a status only with the evidence that moved it, citing a file in `docs/evaluations/` or a dated fact in `docs/verified-facts.md`. When a status becomes **Retire**, open or update the decision record that carries the assumption.
