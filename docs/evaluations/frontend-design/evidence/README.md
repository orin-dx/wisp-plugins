# Evidence notes

Raw notes from the research agents, kept so every claim in `../traceability/` can be traced to its source. They are **not edited after the fact**. Known errors in them are listed in `../verification/VERIFY-1.md` (transcript and repo claims) and `../verification/VERIFY-2.md` (web and documentation claims). Where a note and a verification file disagree, the verification file wins.

Evidence tags used in the notes: `[P]` primary page read, `[S]` search summary only, `[U]` unverified, `[F]` observed in a transcript, `[I]` inference, `[K]` author's own knowledge (not fetched).

Most web pages were read through summarizing fetchers, so quotes are the fetcher's wording, not verbatim page text. Re-fetch before quoting in the constitution or an ADR.
