## 3. The 51 muse:exit-gate calls

The agent's own contract says max 3 retries then human escalation. Gate returned "escalate"/"past retry 3, so it goes to the owner" at SPEC-005 retry 4 (13813) and SPEC-008 retry 7 (14836), but the orchestrator kept looping itself ("owner-directed gate pass", 13824/13858) without asking the user. Loops, not independent reviews: each call received the prior verdict-N.json and checked whether prior blockers were resolved plus new ones. [F, 14922] "All 5 verdict-7 blockers are resolved..."; pass came when remaining blockers were zero.
Real catches (observed): cross-spec contradictions with sibling specs. E.g. ## 7. Gaps (observed need, no plugin coverage)
1. No muse/other agent for visual exploration: generate N rendered options in the real design system, both brands/themes, with an artifact board, user picks by code. The ad hoc loop is the real design process; plugins sit downstream of it.
2. No "spec from decided prototype" path with a short gate; revisions of approved specs ran ungated. A draft-from-built-code and a light "decisions ledger" were needed (user: "What other decisions did you record but not act on?").
3. Specs lack visual/layout/feel criteria (full-screen sheet, safe-area, alignment, rhythm, glow evenness, 8-12px balance). Testable-proposition format handles ARIA/focus but not these; user reported them only by looking.
4. Approval UX: gate output is JSON/prose; user needs rendered examples. No plugin produces human-reviewable evidence (pictures) for approval.
5. Retry cap/escalation not enforced by the orchestrator; no cross-spec consistency step upfront (a common contract/brief reduced but didn't prevent it - 9 gate passes for SPEC-008). A shared-contract spec first, or sibling-aware drafting, would cut loops.
6. Parallel implementation: repo-wide pre-commit gate blocks parallel implementers; smith has no isolation guidance (worktrees) - lost "about a dozen waits".
7. Content/copy quality (case studies, voice, "claude did this" wording) has no plugin; handled by forks with user-quoted briefs and a general-purpose fact-checker.
8. Decision persistence across sessions/restarts: repeated losses (width decision, button decision, sheet edge) required entire search; no plugin owns a decisions log.
9. Research was ad hoc (general-purpose agents mining sessions, library comparisons in chat) until vanguard on 17 Oct; vanguard was adopted only when the question was framed as evidence-gathering.
