## 2. CORRECTIONS vs M2 and Z2
1. M2 "Model: 5.3-Codex / 5.5 exist (not read)". Now: GPT-6 family is current; 5.6 Sol/Luna are the predecessors named on openai.com; Codex deprecations list 5.3-Codex, 5.2. The role cards use `gpt-5.6-terra` (see 3.1).
2. M2 effort mapping "high/ultra for exit-gate" and M2 "effort low..ultra". Model doc lists `low..max` for API; `ultra` is a Codex/subagent value ("when supported"). `none` is unsupported on Astra and 6.1 Sol only; GPT-6 Sol/Luna (the 6.0 ids) still accept `none` [P-sum, page wording is ambiguous: "Sol & Luna: Support none"]. M2's "Reasoning always on for Astra/Sol" is therefore too broad: it holds for Astra and 6.1 Sol.
3. M2 "Luna to max" in Z2 row: unchecked; guide only says Extra high/Max "where supported".
4. Z2 "Hooks stable since v0.124 (Apr 2026), ~12 events": events confirmed as exactly 12 on the hooks page [P-full]; "stable" is not dated on the page, changelog says "Hooks general availability" with the mobile-remote launch (date not captured). Treat v0.124 as [S].
5. Z2 "Stop hook can make gates binding": confirmed, with a precise limit: Stop `block` does not reject the turn, it injects a continuation prompt; `stop_hook_active` is the loop guard and the script must honor it. Stop matchers are ignored. WP-616 `stop_hook_active` item is resolved for Codex.
6. Z2 "Codex reads Claude-format marketplaces (reportedly)": now [P-sum] that `.claude-plugin/marketplace.json` at repo root is supported as legacy format. Still unverified whether it loads Claude `agents/` or `plugin.json` hooks; Agent Plugins core excludes agents/hooks. The Codex desktop app also imports Claude plugins.
7. Z2 "Codex plugin: .codex-plugin legacy overlay + root plugin.json": confirmed. Older changelog (April 2026) says `.codex-plugin/plugin.json` was "Required". It is now fallback only; root `plugin.json` is the portable entry.
8. Z2 "Subagents spawn on explicit request or when AGENTS.md/skill says so": the doc says explicit request, with proactive delegation only at Ultra. Skill text that says "when agent teams are available" is not an explicit request.
9. Z2 `[agents]` list omitted `enabled` and `interrupt_message`; `max_threads` is a legacy alias; no `max_depth` documented.
10. M2 "Sandbox not per-agent overridable": confirmed and extended (also approval_policy, mcp_servers, model_provider).
11. Z2 "Ultrafast on Sol 10-08": model guide says Ultrafast is "Available for GPT-6 Astra"; the latest-model page says Ultrafast covers EU for 6.1 Sol. Pages disagree; treat availability as unsettled.
12. Browser in Codex: Z2 treats in-app browser and Chrome extension as native Codex visual verification. The browser doc says the in-app browser is not in CLI or IDE, and cloud environments do not support browser automation. Visual-evidence adapters must degrade on those surfaces.
13. Z2 "Agent Plugins excludes hooks/agents": consistent; hooks still ship via `extensions.com.openai.hooks`.
