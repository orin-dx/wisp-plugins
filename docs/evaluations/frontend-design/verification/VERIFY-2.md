## Corrections to apply to earlier summaries

1. M1-46/C-12: upgrade from "risk" to "documented trigger". The refusals page lists a `reasoning`/`thinking`/`trace` JSON field and scratchpad sections as the common causes, and says the category has no fallback. Wisp's mandatory `reasoning` field (constitution L242, ~29 schemas) is directly in scope for every Anthropic tier from Fable through Haiku 5.5 per the refusals page. Some refusals are billed. Treat as release-blocking for WP-505/ADR 004: rename/remove the field or replace with a bounded "rationale/evidence" field; run an empirical test (the docs do not say the refusal is deterministic).
2. "Skills too prescriptive" is a Fable 5 page statement only; do not cite as Anthropic-wide.
3. C-1/C-2: verification guidance is per-model (Opus 5: remove; Sonnet 5.5 low: add real-check paragraph; Fable 5: use fresh-context verifier subagents). Sonnet 5.5 cost saving is at `max`.
4. C-4: Opus 5.5 `medium` default is scoped to agentic coding/review. Fable 5.1 default is `high`, Sonnet 5.5 `high` (API), Haiku 5.5 `medium`. Opus 5.5 thinking is always on.
5. Env vars: use `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` (default 3) and `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` (20); `..._PER_SESSION` removed (v2.1.224).
6. C-11: GPT-6.1 Sol is recommended on Codex; GPT-5.6 family still selectable. Ids: gpt-6-astra, gpt-6-sol, gpt-6.1-sol, gpt-6-luna.
7. C-7/WP-70: Codex custom agents are native TOML (required: name, description, developer_instructions). The draft's fact is right; only the repo-policy conflict remains.
8. Figma: get_variable_defs on both servers; Starter limit 20/month (not 6); drop Coinbase 11.5/22.3/22.5; Code Connect blog is 27 tasks/2 systems.
9. Storybook: use test-run, docs-list, docs-show, docs-show-story, get-storybook-story-instructions; preview status; 10.6 referenced.
10. Kaelig: replace "almost none ship llms.txt" with "15 of 21 ship llms.txt, but some serve 404/HTML shells"; use 21 systems/200 affordances/165 techniques (dated).
11. v0 DS 2.0 = 25 June 2026. uSpec = redongreen/uSpec, MIT, 11 skills per secondary source.
12. Atlassian numbers stand; they are averages from an internal playground, task = login screen for the 92% line.
13. WCAG: 2.5.8 AA 24x24; 2.5.5 AAA 44x44. Deque 57% is by issue volume (2021).
