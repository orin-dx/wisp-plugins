## PLAN IMPACT (CATALOG.md rows)
- WP-53 (vocabulary and urgency tiers): STRENGTHENED. Adopt a closed table with one-line meanings modelled on CAP 413 Table 8 (received vs complied vs unable-with-reason vs standby-is-not-approval). Define two severity tiers exactly like distress/urgency (needs immediate action vs does not). Drop "verify" and any "OK is banned" rationale. Add error-recovery words (NEGATIVE + corrected value, CORRECTION). Keep ADR 002 boundary (vocabulary in references, EARS in outputs).
- WP-54 (stall and lost-contact): STRENGTHENED, with nuance. Aviation lost-comms is predefined with fixed timers (7/20 min) and a transponder signal (7600); go-around is predefined with a published point and an explicit "unless ATC instructs or safety dictates" override. Specify per-agent timers and a "declare stall" signal; allow a documented override rather than none. Timers values are Annex 2 via secondary source.
- WP-51 (retry cap, override logging): ADJUST. PIC deviation is allowed only "absolutely necessary in the interests of safety"; the post-hoc report duty is not sourced, so do not cite ICAO for "logged overrides". Cite only the deviation condition; design the log requirement on its own merits. Hear-back finding supports requiring explicit gate confirmation, not silence.
- WP-212 (gate non-monotonicity): LITTLE DIRECT AVIATION IMPACT. Only transferable point: an uncorrected readback is read as consent, so re-check results must state "correct/negative" explicitly. No change to verdict@4 dependency.
- WP-65 (narration brevity): CAUTION, scope stays narrow. Evidence for gains is weak and mostly chat-style: JetBrains 8.5% output ceiling (forced activation), Caveman's own delta over "Answer concisely." is 3%, LemonCrow total cost +0.06%, output ~0.3% of tokens in real sessions. Evidence of harm: CCoT GPT-3.5 -27.69% on math; Adobe input compression raises cost. Keep: concise status/rationale only, never specs/handoffs/gates; use Caveman's fidelity rule set (negations, numbers, payload verbatim, safety prose) as the checklist; run it as a measured A/B vs a "be concise" control, not as a default. Do not cite 65% or the brevity paper's 26 pp.
- WP-60 (paired eval harness): STRENGTHENED. Adopt Caveman's three-arm design (none / generic terse control / treatment) and host-isolation flags, JetBrains ladder (free transcript replay, k=1 smoke, k=3, full, medians + Wilcoxon/sign test, exclude failed pairs in both arms, bill-based cost with long-context tier outliers noted). Note ~80 pairs only rule out large effects. Note SkillsBench itself is a usable external fixture, and its finding "focused Skills (<=3 modules) beat large bundles" feeds WP-62 ablation.

Independent evidence already shows no savings (+7.6% low effort, ~0 at high; ceiling ~3%) on claude-sonnet-5/SkillsBench; the user's own config has the same hook.
