## Highlights

- **Start by intent.** A new `guide` plugin gives six commands (`/guide:explore`, `spike`, `fix`, `build`, `check`, `ship`) that hand off to the skill that does the work. The pipeline plugins redirect a direct agent call to its skill, so the checks it relies on run.
- **Explore before you commit.** `muse:sketch`, `muse:promote` and `smith:spike` give a non-binding path for early ideas: three structurally different options, rendered, with a decision log, and a spike that says what was and was not verified.
- **Gates that stop.** Exit gates and the plan challenger get two rounds, then the decision goes to a human. A hook checks gate output and the retry cap. Gates list every blocker in round one and check claims against the code, build or spec they cite.
- **Less to read.** Specs state unknowns as `Assumption:` or `Open decision:` lines instead of failing for them. Plans state outcomes and contracts, not code. Agent and skill descriptions are about half the size, and agent prompts drop the persona backstory.
- **Changesets users can read.** Courier writes changesets in the repository's own format and style: a bold lead-in, the value, then why it matters, how to adopt it and limits, with `**Breaking:**` and `**Action:**` paragraphs. `courier:pr` leaves PR opening to Entire where a repository says so.
- **Cheaper tiers.** The `claude-fable-5-1` agents and the Codex `judge` role move one tier down, and a Codex author role uses `gpt-6.1-terra`.
- **Installs work.** Marketplace sources are relative paths, so installed plugins include their shared schemas and references.

Removed: `navigator:estimator`. Not measured yet: whether these changes lower gate rounds, turns or tokens (`docs/evaluation-runbook.md`).
