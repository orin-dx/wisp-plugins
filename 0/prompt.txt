  1. Add a render-evidence artifact that the implementation gate requires for UI scope. It would hold screenshots per viewport, theme and state, axe/Lighthouse JSON, and console errors. An unrendered UI should be reported as a coverage gap, never a pass.
  2. Add an explore mode. A throwaway, time-boxed prototype comes first with no spec and no gate. Then derive the spec from the prototype and keep the prototype or its screenshots as the visual oracle. Use change-delta specs to limit churn, and skip the pipeline for one-sentence diffs.

  4. Add a copy-provenance check. Extract the rendered text and diff it against the source copy, flagging invented numbers, names and claims.
  5. Run a token lint plus a computed-style check, and a11y probes for keyboard, contrast and target size. Verdicts should state that automated a11y coverage is partial.
  6. Plans should declare file ownership. Shared primitives and token files get a single writer, and a post-merge render check catches intent conflicts.
  7. The existing fresh-context adversary and exit-gate shape matches Anthropic's guidance. What's missing is browser tools and evidence requirements.
